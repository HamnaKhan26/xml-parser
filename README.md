# 🧩 XML Parser Demo

A Node.js project that efficiently parses **large XML files** and converts them into **CSV** format using streaming.  
This project demonstrates how to handle large datasets without loading everything into memory — ideal for scalable back-end data processing pipelines.

---

## 🚀 Features

- ⚡ **Streaming-based parsing** using [`xml-stream`](https://www.npmjs.com/package/xml-stream)  
  Efficiently processes large XML files line by line.  
- 📁 **CSV output** using [`csv-writer`](https://www.npmjs.com/package/csv-writer)
- 🧠 Memory-safe design (flushes data in batches)
- 🧰 Simple setup and reusable for other XML formats
